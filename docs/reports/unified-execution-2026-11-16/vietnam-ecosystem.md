## Recommendation

Prefer a directly reviewed official OA adapter. ADAPT narrow Sapo guard/read-client and isolated OA queue/credential patterns after local synthetic verification. REFERENCE ChatbotX schemas and fixtures. REJECT adopting personal Zalo sessions, scraping or unmodified autonomous agent tools as production integration authority. ADOPT applies only to the research practice of immutable source pins and explicit unknowns; there is no whole-library ADOPT recommendation.

Repository names, Vietnamese documentation and Vietnam channel focus establish relevance, not corporate domicile. AIECOS owner branding explicitly identifies Vietnam, but legal Vietnam origin remains unverified. The other three owners' legal origin is UNKNOWN. Zalo/Sapo are Vietnam ecosystem providers; none of these community repositories has demonstrated official partner approval in this review.

## Official documentation versus community capability

[Sapo's official private-app guide](https://help.sapo.vn/ung-dung-rieng-private-apps) documents Basic Authentication and separately granted resource permissions. That supports the private-app auth mechanism, not blanket shop access. The [official developer portal](https://developers.sapo.vn/) redirected to partner authentication with no readable API body in this check. Current OAuth scopes, API limits, webhook signatures and mutation idempotency therefore remain UNKNOWN; the community API reference is not substituted for official policy.

The [official Zalo OAuth page](https://developers.zalo.me/docs/official-account/bat-dau/xac-thuc-va-uy-quyen-cho-ung-dung-new) and its official static mirror returned shells without readable detailed body. The [official documentation index](https://developers.zalo.me/docs/) search index distinguishes OA from ZBS Template Message; no current detailed token lifetime, messaging window, ZNS/ZBS eligibility, template approval or partner status was verified. Do not carry older lifetime values or vendor bulk-message claims into requirements. OAuth endpoints and signature algorithms found in community code are SOURCE evidence, not certification by Zalo. OA authorization, approved permissions, template eligibility, consent and a documented contract must be verified for each intended action. Personal QR/cookie/device sessions are a distinct private-protocol route and are not promoted to official OA/ZNS capability by successful login.
