## Contradictions and unresolved evidence

1. Earlier narrative reports used GitHub search/topic URLs for several candidates. Those pointers are replaced in this research set with the canonical repository URLs above where a concrete repository was identified. This replacement does **not** upgrade the rows to verified source evidence.
2. `OneChat` has multiple similarly named products. `https://github.com/One-Chat/OneChat` is retained as the concrete upstream pointer found during research, while ownership, release identity, license and source suitability remain UNKNOWN; the earlier `onechat-io/onechat` pointer is not silently treated as equivalent.
3. `get-mcp-ads` has distinct provider repositories in the matrix. Provider coverage and product-site descriptions must not be collapsed into a single verified package or inferred common dependency tree.
4. `zca-bridge`, `ZaloCRM`, `AIECOS`, Pancake POS MCP and Sapo-MCP remain unresolved where no exact independently captured source identity was available. No absence claim is made.
5. Existing reports describe some licenses and maturity signals from desk-review material. This matrix preserves those as reported signals but leaves exact path/digest, selected release applicability and current status UNKNOWN until a reproducible source capture is attached.
