IMPLEMENTED: PostgreSQL action transition CAS + history event + observed assertion envelope are one transaction (migration014). Execute and verify use the same persistence helper. A failed outbox insert rolls back the outcome transition; the prior EXECUTING state remains visible for recovery. No executor/catalog enablement changes.

Delivery is at least once. PgAssertionDelivery claims at most20 records with SKIP LOCKED, leases30seconds, sink timeout10seconds, exponential backoff capped1hour, maximum5attempts. PgAssertionInbox deduplicates workspace/assertionId and never mutates Commercial State. The original envelope is immutable; operational delivery state may change. Memory runtime keeps explicit best-effort test-only delivery and has no durability claim.
