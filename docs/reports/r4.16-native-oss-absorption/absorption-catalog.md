# Native OSS absorption catalog

Upstreams are source material, not runtime applications. Atomic CRM contributed selected React modules; its domains/backends were deeply inventoried and deferred/rejected where Northstar differs. Chatwoot contributed a pure helper and interaction reference; Rails/Vue/Redis/ActionCable/database/auth are excluded. Ads Studio contributed table/chart adaptation; FastAPI/SQLAlchemy/auth/optimization are excluded. Twenty UI was evaluated but not adopted.

No upstream migrations, authentication systems, parallel databases, independent APIs or production services are required by Northstar.
