## Validation and release criteria

First rerun the existing exact-baseline lanes through coordinator-owned isolated resources. After integration: focused source/schema/HTTP/PG tests, typecheck/lint/build, strict architecture/registry/security checks, complete integration registry with no missing/skipped suites, full test/coverage, browser signed-auth journey and restart/idempotency negatives. Record exact source SHA, command, result, fixture provenance and whether PG/browser/network participated. Passing tests with memory store do not replace PostgreSQL durability; controlled browser responses do not replace actual signed-auth/CSRF checks.

Acceptance is limited to a disabled synthetic foundation. Gate B remains conditional; no human study or comprehension KPI exists in this audit. Gate C remains NOT READY for real customer data; deletion/retention/key custody/legal hold/backup erasure and production IdP/TLS/rights remain separate gates. Local PASS cannot become hosted-CI PASS without a successful run on the exact revision. No push/deploy is authorized by this report.
