## Actual registered application surface

`AppModule` imports `HealthModule`, `PilotLoopModule` and `OidcAuthModule`. Its controllers provide Operator HTML, integration enroll/upload/health, hybrid observations/provider-read/reconciliation, memberships/browser login, synthetic source connections/evidence, source links and sync health. `PilotLoopModule` registers pilot/closure, contact attempts, manager exceptions, feedback/telemetry/learning, exports/lifecycle and internal assertion-delivery operations. The selected runtime uses actual Nest AppModule, not separate test-only controller mocks.

Registration does not imply live-provider availability. The R4.15 supported Sales pilot cleans inherited environment and enables `SYNTHETIC_PILOT_ONLY`, OIDC, PostgreSQL and the explicitly synthetic source/Hybrid fixture flags. Source/Sync panels are conditioned on session flags and show fabricated observations with UNKNOWN completeness; no real provider credential or endpoint is enabled. Assertion delivery remains disabled. The separate Hybrid Preview owns its own fabricated scope and database.
