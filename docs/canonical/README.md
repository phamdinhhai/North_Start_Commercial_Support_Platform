Rules:

1. Delivery agents read these files; normal implementation tasks do not edit them.
2. Architecture-changing proposals go through RFC / ADR + human approval.
3. North Star is source material, but canonical docs are the normalized enforceable layer.
4. BMad may validate/decompose/update delivery artifacts; it does not silently override frozen canonical decisions.
