# Marketing -> Sales Handoff Playbook

**Owner:** CS / Sales Ops / Marketing Ops  
**Maturity:** Draft  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


## Required handoff package
Lead ID, customer identity, phone/contact, original channel, source/campaign when known, conversation summary, full evidence link, needs, product interest, objection, commitments, Marketing owner, Sales owner, handoff timestamp.

## SLA sequence
Qualified -> handoff created -> Sales accepted -> first contact -> contact outcome -> next action.

## Failure recovery
If phone/Zalo fails, inspect original-channel activity and recommend/use original channel when permissions and platform rules allow.
