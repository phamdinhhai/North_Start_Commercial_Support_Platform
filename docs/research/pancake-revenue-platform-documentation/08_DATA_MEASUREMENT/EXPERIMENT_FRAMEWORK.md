# Experiment Framework

**Owner:** Product / Data  
**Maturity:** Draft  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


## Pilot design
Baseline 2-4 weeks of current operation, then compare treatment cohort using the platform.

## Primary outcomes
First-contact time, contact success, follow-up completion, missed-lead rate, source linkage coverage, outcome capture, manager reporting time.

## Guardrails
Customer complaints, Sales workload, AI correction rate, wrong-channel messages, privacy/security incidents.

## Rule
Do not claim revenue lift without a credible baseline, attribution caveat, and measurement-coverage disclosure.
