# Funnel Definitions

**Owner:** Data / Revenue Ops  
**Maturity:** Requires customer configuration  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


Canonical funnel: Spend -> Conversation -> Lead -> Qualified -> Handoff -> Sales Contacted -> Engaged -> Follow-up/Opportunity -> Won/Lost -> Revenue.

Each implementation must define exact entry/exit criteria and timestamps for every stage. Tags alone are not accepted as authoritative stages unless mapped through explicit transition rules.
