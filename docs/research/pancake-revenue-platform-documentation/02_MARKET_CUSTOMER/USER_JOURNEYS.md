# Current and Target User Journeys

**Owner:** Research / Design  
**Maturity:** Draft v0.1  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


## Current common journey
Meta/social -> Pancake conversation -> Marketing qualification -> phone number -> manual handoff -> Sales phone/Zalo -> fragmented follow-up -> outcome recorded inconsistently.

## Target journey
Acquisition source -> Pancake conversation -> structured Lead ID -> relationship-rich handoff -> Sales work queue -> phone/Zalo/original channel -> commercial events and commitments -> verified outcome/revenue -> attribution and Marketing feedback.

## Failure points to validate
- context loss at handoff;
- source lineage loss;
- first-contact delay;
- unreachable customer despite active original channel;
- forgotten commitments;
- stale tags/notes;
- outcome not written back;
- reporting stops at team/system boundaries.
