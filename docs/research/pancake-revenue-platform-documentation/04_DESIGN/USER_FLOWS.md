# Core User Flows

**Owner:** Design / Product  
**Maturity:** Concept  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


## Flow A - Marketing handoff
Conversation -> qualify -> create Lead ID -> generate handoff summary -> assign Sales -> SLA begins.

## Flow B - Sales first contact
Open assigned lead -> review context -> choose phone/Zalo/original channel -> log/infer outcome -> create next action.

## Flow C - Commitment
Conversation/activity -> detect commitment -> evidence + due date -> auto-create or request confirmation -> complete/overdue.

## Flow D - Manager intervention
Exception detected -> open evidence -> assign/recover/escalate -> resolution logged.

## Flow E - Revenue feedback
Won/Lost + revenue -> connect to Lead ID -> source attribution/data health -> Marketing quality report.
