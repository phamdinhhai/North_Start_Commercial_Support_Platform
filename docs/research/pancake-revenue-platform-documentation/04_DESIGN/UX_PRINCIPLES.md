# UX Principles

**Owner:** Design / Product  
**Maturity:** Decision  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


- Exception-driven, not form-driven.
- Minimize duplicate data entry.
- Evidence is one click away from every AI inference.
- Prefer confirmation of ambiguous truth over hidden automation.
- Keep unknown explicit.
- Preserve the user's existing primary workspace where possible.
- Sales should see commercial context, not inbox noise.
- Every state change should be explainable and undoable.
