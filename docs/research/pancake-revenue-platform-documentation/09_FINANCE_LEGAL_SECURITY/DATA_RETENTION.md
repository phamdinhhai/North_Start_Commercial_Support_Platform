# Data Retention Policy - Requirements

**Owner:** Legal / Security  
**Maturity:** Not yet policy  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


Define retention separately for raw messages, AI-derived events, audit logs, connector tokens, analytics aggregates, deleted customers, and model-evaluation samples. Support configurable retention where enterprise customers require it. Do not retain raw conversation data indefinitely by default without a business/legal reason.
