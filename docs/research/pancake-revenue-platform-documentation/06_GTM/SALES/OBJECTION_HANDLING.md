# Objection Handling

**Owner:** GTM / Sales  
**Maturity:** Hypothesis-led  
**Evidence status:** Mixed: verified facts, user observations, inference, hypotheses  
**Last consolidated:** 2026-09-09


## "We can just add more Pancake users"
That may solve access. Validate whether it also solves lead-scoped context, cross-team ownership, follow-up obligations, source-to-revenue lineage, and Marketing/Sales measurement.

## "We should just buy a CRM"
If the organization already needs complex opportunities, forecasting, accounts, and governance, a CRM is correct. The platform should integrate rather than block that move.

## "We already use Sheets"
Sheets can store state but do not automatically preserve interaction evidence, commitments, channel continuity, or source lineage across handoff.

## "AI can be wrong"
Agree. The design uses evidence, confidence, policy, audit, and human confirmation for ambiguous/high-impact actions.
