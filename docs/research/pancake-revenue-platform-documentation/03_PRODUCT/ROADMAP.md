# Outcome and Learning Roadmap

**Owner:** Product Lead  
**Maturity:** Active, branchable roadmap  
**Evidence status:** Sequence of tests, not feature commitment  
**Last updated:** 2026-09-10  
**Supersedes:** 2026-09-09 feature-phase roadmap for the current phase

## Loop 0 — Internal comprehension

**Outcome:** A person outside the design work can complete the core journey using clearly synthetic data.  
**Learns:** UX/task comprehension only; not demand.  
**Branch:** Fix blockers or simplify.

## Loop 1 — External workflow exposure

**Outcome:** A real target-role participant uses the instrumented manual-input product on an allowed workflow.  
**Learns:** Whether context handoff is consumed and useful in scope.  
**Branch:** Continue context bet, narrow job/role, pivot input/output or stop.

## Loop 2 — Repeat action behavior

**Outcome:** A tester returns across leads/days and uses next actions/outcomes without heavy prompting.  
**Learns:** Whether follow-up/minimal truth can support repeat value.  
**Branch:** Continue queue, narrow to one action job, or remove process burden.

## Loop 3 — Integration/intelligence leverage

**Outcome:** Verified Pancake read sync and/or evidence-linked AI reduce friction without trust/integrity regression.  
**Learns:** Whether optional technology improves the validated workflow.  
**Branch:** Default-on, keep optional, redesign or retire.

## Loop 4 — Buyer and viability

**Outcome:** A buyer uses observed results to make a real commitment: data/time/process/payment/pilot.  
**Learns:** Buyer, implementation burden and willingness to pay.  
**Branch:** Paid pilot, change packaging/buyer, verticalize or stop.

## Future candidates, not sequenced commitments

CRM bridge, acquisition intelligence, manager funnel, data health, attribution and revenue intelligence return to roadmap only when evidence identifies them as the next constraint. Prior feature roadmap remains historical context in version control/decision log.

## Expansion rule

Do not expand beyond Loop 2 without an external tester. Every loop records product version, experiment, evidence, limitations and Continue / Narrow / Pivot / Stop decision.
