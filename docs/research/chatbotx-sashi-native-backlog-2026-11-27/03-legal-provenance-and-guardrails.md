## 2. Clean-Room & Security Enforcement Rules for Product Agents

1. **Strict Information Barrier During Implementation:** Product engineering sessions implementing `NCB-*` items MUST read only repository specifications (`docs/canonical/**`, `docs/implementation-plan/**`, `docs/research/chatbotx-sashi-consolidated-audit-2026-11-26/`, and this folder) and MUST NOT open, mount, or copy from any external `ChatbotX` clone or Sashi client bundle.
2. **Honest Provenance Claim:** Because Phase 1/2 research agents inspected `ChatbotX@fdd7ccf4...` to author behavioral traces, North Star claims **non-copying independent implementation across distinct stacks** (NestJS + Fastify + raw `pg` SQL vs Next.js + oRPC + Drizzle + BullMQ + Redis), **not** a two-team Chinese-wall legal certification (`H0/04-legal-and-provenance-assessment.md` §3.1).
3. **Mandatory Pre-Copy Gate (`R-41` / `F-037`):** Even for `LX-02` (`timezone.ts`), direct file copy remains prohibited unless a deterministic SPDX/CycloneDX SBOM, enterprise-exclusion proof, third-party `NOTICE` bundle, and written Owner/legal ADR are committed first.
4. **Private API & PII Prohibition (`ADR-007` §5, `ADR-009`):**
   - Reverse-engineered sockets, browser-companion DOM/network frames, or undocumented provider endpoints may **never** execute production mutations and require written provider permission on file before production read promotion.
   - Customer content digests must use server-held workspace-keyed HMAC-SHA256 (`ContentDigester`, `b9b6155`), and quarantined raw research frames must remain disabled by default or bounded to `<=7` days under `research-capture-encryption-v1` (`6e98238`).

## 3. Evidence Claim Rules

- `DOCUMENTED` / `DOCUMENTED_UI_REVIEWED`: establishes documented vocabulary or visible controls only; not hidden formulas or backend enforcement.
- `SOURCE_INSPECTED` / `STATIC_TRACE_COMPLETE`: establishes source-level shape at an exact donor SHA; not North Star compatibility or runtime behavior.
- `UPSTREAM_TEST_EXECUTED`: establishes selected donor/PoC package tests only; not legal clearance or production behavior.
- `CONTROLLED_EXPERIMENT_VERIFIED`: establishes the exact fixture/runtime tested; generic PG 18.7 cannot close native PG 16 migration acceptance.
- `RUNTIME_OBSERVED`: establishes only the recorded read-only capture or exact North Star acceptance run.
- `UNKNOWN` / `BLOCKED` / `NOT_AUTHORIZED`: preserved per `I-08`; never promoted to PASS by prose.
