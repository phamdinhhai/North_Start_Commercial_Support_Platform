## Concrete acceptance backlog, not implementation

1. Credential tuple-bound lookup/refresh lock; two tenants with same native ID never share tokens; revoke/delete mid-refresh cannot resurrect; rotation/concurrency/timeout/cooldown and sanitized-error tests. Reconnect cannot clear auth failure.
2. Subscription operation ID, remote ID, compensation failure and admin repair; repeated disable handles 404; enabled only after durable receipt; feedback-loop origin protection. Remote operations individually gated.
3. Separate upload sequence/provider token/event ID; atomic receipts/checkpoints; partition bounds/lookback/late events, crash-before-commit/retry/conflicting duplicate and retention-reset tests. Snapshot cannot reconstruct lost edits/deletions.
4. Signed HTTP bytes verified before parse, freshness plus durable dedupe; scope and Lead policy separately. Outbox timeout does not prove sink cancellation, so idempotent sink remains necessary.
5. Conversation direction/delivery/assignment/status/deletion fixtures without Lead-state changes, identity merge, revenue inference or inbox-wide access.
