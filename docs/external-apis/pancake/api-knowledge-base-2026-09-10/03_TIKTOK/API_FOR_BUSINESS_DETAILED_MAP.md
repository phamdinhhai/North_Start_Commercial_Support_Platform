# TikTok API for Business — detailed map

## Marketing API
Không chỉ Campaign/Ad/Reporting. Current docs inventory bao gồm:
- onboarding, auth, rate limits, permissions, sandbox;
- Business Center: members/partners/assets/asset groups/finance/payment/reporting;
- Manual Campaign, Copy Campaign, Upgraded Smart+, legacy Smart+ migration;
- App promotion, Website conversions, Sales, Reach & Frequency, TopView, Dedicated Campaign;
- Super Split Test, Campaign Budget Optimization, Promote, realtime/placement/targeting;
- creatives: video/image/music, playable, Instant Page, CTA, interactive add-ons, cards, stickers, premium add-ons, disclaimers, Spark Ads;
- audience management;
- catalog/feed/product/product-set;
- Lead Generation: obtain/export leads + CRM postback;
- reporting + webhook subscription + MMM data request;
- Events API / Pixel / App Events SDK / Event Gateway measurement stack.

## Organic API
- Accounts
- Mentions
- TikTok One (TTO)
- Discovery
- Spark Ads Recommendation

Accounts API còn bao gồm profile/post insights, business benchmark, comments, post publishing, privacy, hashtags/location tags, post-ad authorization và webhooks.

## Business Messaging API
- direct messages / thread management
- real-time send/receive
- automatic messages
- welcome message
- suggested questions
- chat prompts
- unlock conversations
- messaging limits
- webhook events
- data-security/privacy review
