# TikTok Research API + VCE + Commercial Content API

Research & Insights hiện không chỉ có Research API và Commercial Content API. **VCE (Virtual Compute Environment)** là một research tool riêng cho approved research projects.

- Research API: programmatic public-data queries theo eligibility.
- VCE: secure compute environment; query/analyze public data trong môi trường kiểm soát.
- Commercial Content API: commercial-content transparency/analysis.

Nguồn:
