# TikTok GO

TikTok GO kết nối local businesses với TikTok discovery bằng merchant tools/integration APIs. Docs hiện có TikTok GO Dining với merchant flows và API Reference cho merchant markets.

## Nhóm API đã xác minh ở catalog
- Shop Management
- Product Management
- Voucher Management
- OAuth/token
- Error codes/category tree/supporting reference

Scopes hiện thấy trong TikTok Scopes Reference:
- `local.shop.manage`
- `local.product.manage`
- `local.voucher.manage`

Nguồn:
- https://developers.tiktok.com/docs/en/tiktok-go-landing
- https://developers.tiktok.com/docs/en/tiktok-api-scopes
