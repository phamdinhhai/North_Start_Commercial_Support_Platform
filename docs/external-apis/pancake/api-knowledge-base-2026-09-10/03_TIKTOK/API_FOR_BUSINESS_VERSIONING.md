# TikTok API for Business — versioning snapshot

Current official API for Business documentation describes non-MCP request URLs as:

`https://business-api.tiktok.com/open_api/v1.3/{endpoint}`

and identifies **v1.3** as the current API version in that reference.

Do not generalize this to TikTok for Developers or TikTok Shop:
- TikTok for Developers uses separate `open.tiktokapis.com` versioned endpoints such as `/v2/...`.
- TikTok Shop places a version inside each business-area endpoint path and different APIs may have different active versions.

Official reference: https://ads.tiktok.com/gateway/docs/index?doc_id=1735713875563521
