# TikTok APIs — Tổng quan

TikTok có ít nhất ba hệ sinh thái API độc lập cần phân biệt:

1. **TikTok for Developers** — https://developers.tiktok.com/doc/
2. **TikTok API for Business** — https://ads.tiktok.com/gateway/docs/
3. **TikTok Shop Open API** — https://partner.tiktokshop.com/docv2/page/tts-developer-guide

Không dùng token/base URL của một hệ để gọi hệ khác.

## TikTok for Developers

Product list hiện gồm Share Kit, Login Kit, Content Posting API, Research API, Display API, Embed Videos, Data Portability API, Green Screen Kit và Commercial Content API; portal còn có một số sản phẩm/capability mới theo từng chương trình.

## TikTok API for Business

Official overview chia thành:
- Marketing API
- Organic API
- Business Messaging API

## TikTok Shop

E-commerce API riêng cho product/order/fulfillment/finance/affiliate và nhiều nghiệp vụ seller/partner khác.
