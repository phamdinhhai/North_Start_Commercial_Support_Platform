# Quick Reference — các base URL quan trọng

```text
Pancake User API       https://pages.fm/api/v1
Pancake Page API v1    https://pages.fm/api/public_api/v1
Pancake Page API v2    https://pages.fm/api/public_api/v2

Meta Graph API          https://graph.facebook.com/{version}
Threads API             https://graph.threads.net

TikTok Developers       https://open.tiktokapis.com/v2
TikTok Business         https://business-api.tiktok.com/open_api/v1.3
TikTok Shop             https://open-api.tiktokglobalshop.com
```

## Đừng nhầm

- TikTok Commercial Content API != TikTok Marketing API.
- TikTok Display API != TikTok Organic API.
- TikTok Business Messaging API != Data Portability Direct Messages export.
- TikTok Shop API != TikTok API for Business.
- Meta Messenger API/Instagram Messaging API != Pancake API dù Pancake có thể kết nối các channel đó.
