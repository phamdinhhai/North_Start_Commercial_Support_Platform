# Meta Ad Library API

Đây là một API transparency/research **không nên nhầm với Marketing API**.

## Khả năng chính
- Tìm ads về social issues/elections/politics đã delivery toàn cầu trong phạm vi retention được công bố.
- Với UK/EU, API cũng có transparency data cho các loại ads rộng hơn trong phạm vi thời gian vendor công bố.
- Trả về ad library ID, creative content, Page name/ID, delivery dates, publisher/platform placement và các transparency fields tùy loại ad/region.

## Endpoint đã xác minh
`GET /ads_archive`

## Access
Yêu cầu Facebook account, Meta developer setup và quy trình authorization/identity-location tương ứng.

Nguồn chính thức: https://www.facebook.com/ads/library/api/

## Liên quan dự án
P3. Hữu ích cho competitive/creative research; **không phải** nguồn để đọc spend/insights của ad account khách hàng.
