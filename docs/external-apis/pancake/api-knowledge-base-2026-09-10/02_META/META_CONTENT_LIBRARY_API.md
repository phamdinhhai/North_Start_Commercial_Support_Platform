# Meta Content Library & API

Restricted research interface cho public content trên Facebook/Instagram; Meta cũng đã bổ sung Threads data vào Content Library UI và mở rộng comments/API theo các cập nhật công bố.

## Quan trọng
Đây **không phải API production bình thường cho SaaS thương mại**. Access dành cho nhóm researcher đủ điều kiện và được phê duyệt, thông qua môi trường nghiên cứu được kiểm soát.

Nguồn chính thức:
https://about.fb.com/news/2023/11/new-tools-to-support-independent-research/

Project relevance: `OUT` cho core product, nhưng phải có trong “Meta all APIs” inventory.
