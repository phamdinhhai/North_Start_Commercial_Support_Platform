# Meta — bản đồ toàn hệ developer

Meta for Developers hiện chia developer ecosystem thành bốn trung tâm lớn:

1. **Social technologies** — Facebook Login/Graph, Instagram Platform, WhatsApp Business Platform, Threads; cùng các business/ads APIs liên quan.
2. **AI** — Llama/Meta Model API và các tài nguyên model/inference.
3. **Meta Horizon OS** — Unity, Unreal, Spatial SDK, Native/OpenXR, Android Apps, Platform SDK và server-to-server/platform capabilities.
4. **Wearables** — Device Access Toolkit (iOS/Android) và Web Apps cho AI glasses/display.

Nguồn: https://developers.meta.com/

## Liên quan dự án

Dự án Revenue/Commercial Continuity hiện ưu tiên **Social technologies + Ads/Marketing**. AI/Horizon/Wearables vẫn được inventory để thỏa yêu cầu “Meta API tất cả”, nhưng đánh `OUT` vì không nên đưa vào integration roadmap hiện tại.

## Meta Horizon

API reference chính thức cung cấp build paths cho Unity, Unreal, Meta Spatial SDK, Native/OpenXR và Android Apps. VR Platform SDK có các package như Application, Application Lifecycle, Consent, Group Presence, In-app Purchases, Leaderboards, User Age Category và Users.

Nguồn:
- https://developers.meta.com/horizon/reference/
- https://developers.meta.com/horizon/documentation/android-apps/ps-platform-sdk-overview/

## Wearables

Device Access Toolkit expose camera/audio/display capabilities cho iOS/Android; Web Apps dùng HTML/CSS/JavaScript và các sensor/input phù hợp. Hiện availability/publishing còn phụ thuộc developer preview/market.

Nguồn: https://developers.meta.com/wearables/
