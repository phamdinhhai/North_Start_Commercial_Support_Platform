# Meta — legacy/deprecated/transition surfaces

Mục tiêu của file này là tránh AI gặp tài liệu cũ rồi tưởng vẫn là API hiện hành.

- WhatsApp On-Premises API: legacy/deprecated; ưu tiên Cloud API.
- CrowdTangle: sunset; Meta Content Library/API là research successor cho các use case đủ điều kiện.
- Facebook Groups API: không được dùng làm nền cho integration mới; cần kiểm tra changelog/version nếu gặp tài liệu cũ.
- Commerce/Order Management/Shop surfaces có deprecation theo Graph/Marketing version và thay đổi commerce strategy; luôn kiểm tra changelog hiện hành trước khi dùng.
