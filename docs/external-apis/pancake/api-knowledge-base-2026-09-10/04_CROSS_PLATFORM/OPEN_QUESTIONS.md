# Các câu hỏi API còn mở

## Pancake

- Webhook events/signature/retry chính xác là gì?
- API v1/v2 endpoint nào preferred và migration policy ra sao?
- Conversation payload có campaign/ad/adset/post/source identifiers nào cho từng channel?
- Outbound message restrictions theo channel?
- Terms có cho phép product bên thứ ba cung cấp lead-scoped messaging UX không?

## Meta

- Permission tối thiểu để SaaS chỉ đọc Ads Insights của customer là gì trong app setup thực tế hiện hành?
- Meta Page/IG identifiers có map được Pancake identifiers với coverage bao nhiêu?
- Direct messaging có thật sự cần hay Pancake API đủ?
- Lead Ads có nằm trong ICP đầu tiên không?

## TikTok

- Business Messaging API khả dụng cho advertiser/business account ở Việt Nam ra sao?
- API for Business permission/access tier onboarding thực tế mất bao lâu?
- TikTok ad/conversation identifiers có join deterministic được không?
- TikTok Shop có thật sự thuộc commercial journey của ICP hay là scope riêng?

## Cross-platform

- Source lineage key nào tồn tại từ acquisition → conversation → lead?
- Identifier nào được phép lưu theo terms/privacy?
- Retention/deletion nghĩa vụ theo từng vendor?
