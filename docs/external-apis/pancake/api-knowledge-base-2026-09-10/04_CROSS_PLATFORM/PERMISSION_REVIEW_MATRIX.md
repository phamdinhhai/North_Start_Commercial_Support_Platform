# Ma trận permission / review

| Hệ | Review/approval có thể cần | Rủi ro chính |
|---|---|---|
| Pancake | quyền user/Page + điều khoản Pancake | Page token mạnh, query-param credential, commercial terms |
| Meta Pages/Messenger | App Review + Advanced Access cho khách hàng ngoài app owner | permission dependencies, messaging policies/window |
| Meta Marketing | Standard vs Advanced Access; Business Verification | ads permissions + business asset assignment |
| Meta Instagram | App Review + professional account requirements | FB-linked vs IG Login models, messaging scopes |
| Meta WhatsApp | business verification/onboarding/App Review tùy partner model | WABA/phone ownership, templates/policies |
| TikTok for Developers | app/product review; scope approval; Research/Data Portability eligibility | unaudited clients, restricted scopes |
| TikTok API for Business | developer app permission/access level; security/privacy review cho messaging | region/account availability |
| TikTok Shop | developer/app onboarding, scopes, seller/partner/creator authorization | market-specific compliance, app category/scope |

Không coi approval là chắc chắn cho đến khi app/account thật được duyệt.
