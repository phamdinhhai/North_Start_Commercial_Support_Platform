# Bộ context kế hoạch cho AI Coding

Đây là entrypoint cho AI/coding team của phase hiện tại.

## Đọc theo thứ tự

1. `AGENTS.md`: quy tắc bắt buộc và cách chọn việc.
2. `docs/project/CURRENT_STATE.md`: gate, blocker và việc gần nhất.
3. `docs/project/LEAN_EXECUTION_PLAN.md`: **active plan** cho Lean Validation Product.
4. Product knowledge repository: `00_EXECUTIVE/LEAN_VALIDATION_PHASE.md`, learning registers và `03_PRODUCT/LVP_PRODUCT_SPEC.md`.
